# duolingo-japanese-vocabulary

A Next.js web app that shows Japanese vocabulary from Duolingo Japanese course. It takes CSVs exported from Notion databases as input and generates a static site.

Due to the 2026 course update, the units from section 1 unit 1 to section 3 unit 14 are from the old course, and the units thereafter are from the new course.

## Setting up the local development environment

```bash
pnpm install
pnpm dev
```
